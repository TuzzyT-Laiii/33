# 情境命名与定义

本文件是全项目情境命名的唯一定义，依据 2026-10-29 用户确认的命名（[确认记录](../results/eight-city-flex-value-20261029/confirmed-scenario-names.md)）。正文、图注和新报告一律使用下列名称；旧配置编号只在本文第 5 节对照表出现。

## 1. 命名规则

情境 = **服务器类型 × 用途 × 规模**。

- 中文全称：「服务器类型·用途·规模」，例如「GPU 主导型·大模型训练/开发·100MW」。
- 情境标识：`服务器类型代码-用途代码-规模`，例如 `D-TRN-100MW`，用于文件名、表格和程序字段。
- 数据来源只作为用途的建模依据，不进入情境名称。
- 规模取参考 IT 功率 1MW、10MW、100MW、500MW。

## 2. 维度一：服务器类型（每台或每柜 CPU∶GPU）

| 代码 | 名称 | CPU∶GPU | 参考机型 | 冷却 | 物理含义 |
| --- | --- | --- | --- | --- | --- |
| A | 纯 CPU 型 | 2∶0 / 台 | Lenovo SR650 V3，双路 Xeon Gold 6448Y | 风冷 | 传统通用服务器，不配 GPU；对应超算 CPU 分区和通用云机房 |
| B | CPU 主导型 | 2∶1 / 台 | SR650 V3＋1 张 H100 PCIe | 风冷 | 通用服务器插一张加速卡；CPU 颗数多于 GPU |
| C | 均衡型 | 2∶2 / 台 | SR650 V3＋2 张 H100 PCIe | 风冷 | CPU 与 GPU 颗数相等的通用加速节点 |
| D | GPU 主导型 | 2∶8 / 台 | NVIDIA DGX H100 | 风冷 | 标准八卡 AI 服务器，GPU 承担主要算力和电耗 |

2026-11-01 的典型曲线 v3 采用 A–D 四种风冷服务器类型。E 纯 GPU 型（整柜液冷）已按用户要求移出当前分析范围；此前结果保留其历史范围。

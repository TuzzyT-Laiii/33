## 重新生成

先按第四章v7目录准备#38正文及敏感性的汇总小时缓存，运行 `analysis/summarize_seren_jobs_for_brief.py` 在服务器只读统计作业表，再运行 `analysis/update_chapter4_trn_seren.py` 更新训练、总览及汇总。其余八情境按v6原字节保留。再在本目录运行：

```
npm install
node build.js 数据中心任务时间柔性简表.docx README.md
```

脚本重新生成时会保留“数字来源与说明”和“重新生成”两节，并补充第四章图件与数据来源。

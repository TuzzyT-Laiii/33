## 二、任务时间柔性分类

① 刚性：不能推迟、不能拆分，有人在等或持续在线服务。② 可推迟·整体：可以晚点运行，开始后一次完成。③ 可推迟·可拆分：可以晚点运行，也可在存档点暂停后续跑。未知：数据看不出用途，保守处理。

### 两个收益指标的计算方法

在同一网格、情境、目标和供能边界内配对：C_E,0为无柔性能源系统成本，C_E,1为有柔性能源系统成本，C_add为新增算力费用，ΔC为模型节省金额；当前全部最优解C_add为零。能源费用含风光储、市电及碳成本，延误、检查点恢复和有效产出损失未计入。

ΔC = C_E,0 − C_E,1 − C_add。

指标一为能源侧柔性收益率η_E，表示柔性节省占无柔性能源系统成本的比例。

η_E = ΔC / C_E,0 × 100%。

指标二为柔性收益占机群年化成本的比例ρ_K。T为实际参与优化的原生窗口小时数；ΔC×8760/T为等效年化节省，缺测小时不补齐，折算值不代表完整全年实际收益。

ρ_K = [ΔC × (8760/T)] / A_K × 100%。

机群年化成本沿用当前设备计价：折现率r=8%、寿命L=4年、固定运维比例f=3%，CRF为资本回收系数，合计年化系数0.331921。N_eff为参考服务器台数乘原生窗口峰值利用率的等效台数，P为整机价；两者为模型参数，未核实完整实物库存。下表列出各情境分母。

A_K = N_eff × P × [CRF(r,L) + f]。

**Fig. 2 | Wind resource and grid reliance set where flexibility pays.**
**a,** Median planning-stage energy-system cost savings across bins of annual mean wind capacity factor for scientific computing (CPU, purple), cloud computing (CPU, ochre), scientific AI (blue), LLM training (green) and inference (orange). GPU uses employ the GPU-heavy specification. Lines connect bin medians; markers and line styles distinguish uses. The green band spans the 25th–75th grid percentiles for LLM training. Counts below the axis give grids per bin, identical for the five scenarios (4,842 in total per scenario). Bins are right-closed, the first includes zero, and positions are equally spaced by category. LLM-training medians increase from 9.4% below 0.05 to 20.4% above 0.45.
**b,** Grid-level LLM-training savings versus electricity drawn from the grid as a fraction of facility demand in the optimum without flexibility, at the planning boundary (n = 4,842 grids). Each point represents one grid; colour indicates annual mean wind capacity factor. Pearson's correlation is −0.88.
**c,** Ordinary least-squares coefficients for eight exogenous predictors in the same five representative scenarios, separately for planning and as-built boundaries (n = 4,842 grids per fit). Predictors are standardized within each fit; the outcome remains in percentage points of energy-system cost savings. Red and blue indicate positive and negative coefficients, respectively. Cell values give percentage points per predictor standard deviation, rounded to one decimal. Bold values identify predictors whose omission reduces R² by at least 0.02; R² values appear below each column. This criterion describes model importance. It is not a significance test.
All panels use the economic optimum without an imposed local carbon-free matching target. Resource and temperature features describe 2025; load windows differ in duration and timing, including 120 hours for cloud computing. The regressions describe associations and do not adjust for spatial autocorrelation. Source data are provided.

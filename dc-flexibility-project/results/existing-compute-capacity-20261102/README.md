# 既有算力容量与任务时间柔性

原生需求序列在其窗口峰值以下存在时间空档。按相同窗口峰值配置机群时，五类用途的平均余量为 24.86%–40.21%。这为使用现有设备承接推迟任务提供了候选空间；可调量还取决于任务期限、CPU/GPU 联合资源、显存、互联和运行权限。

## 原生资源口径

下表使用既有 10 MW 情境的原生资源字段，先排除来源明确标记为未知的小时，再计算“平均值÷该窗口峰值”。全部 11 个情境均纳入。B、C、D 分别表示 CPU 主导型、均衡型和 GPU 主导型，相同用途沿用同一归一化需求序列。

| --- | ---: | ---: | ---: |
| A-HPC：纯 CPU 型·科研计算 | 7,416 | 64.83% | 35.17% |
| A-CLD：纯 CPU 型·云通用计算 | 120 | 63.56% | 36.44% |
| B-SAI：CPU 主导型·科研 AI | 5,688 | 59.79% | 40.21% |
| C-SAI：均衡型·科研 AI | 5,688 | 59.79% | 40.21% |
| D-SAI：GPU 主导型·科研 AI | 5,688 | 59.79% | 40.21% |
| B-TRN：CPU 主导型·大模型训练/开发 | 2,057 | 70.06% | 29.94% |
| C-TRN：均衡型·大模型训练/开发 | 2,057 | 70.06% | 29.94% |
| D-TRN：GPU 主导型·大模型训练/开发 | 2,057 | 70.06% | 29.94% |
| B-INF：CPU 主导型·推理服务 | 4,439 | 75.14% | 24.86% |
| C-INF：均衡型·推理服务 | 4,439 | 75.14% | 24.86% |
| D-INF：GPU 主导型·推理服务 | 4,439 | 75.14% | 24.86% |

分母为该研究窗口的需求峰值。这些比例不直接给出现实集群可用的空闲卡数。各字段的含义如下。

- HPC 使用 CPU 核心分配量的归一化代理。
- CLD 使用整机 CPU 小时占用率。较低的占用率本身不能确认已分配核心已经释放。
- SAI 使用已分配 GPU 小时的归一化需求，缺少逐卡空闲状态。
- TRN 使用 Seren 已分配 GPU 小时除以完整作业表瞬时并发峰值 2,032；对该基准的均值为 64.87%、峰值为 92.60%。表中 70.06% 采用观测窗口峰值作为分母。2,288 张来源物理库存用于原功率反推，与需求归一化分母分别记录。
- INF 使用推理子集 GPU 资源小时。4,440 小时中有 1 小时标记为未知，本表从均值和余量统计中排除，保留未知状态。

统计详情见 [native-capacity.json](native-capacity.json)，包括源字段、峰值、有效小时、未知小时、近峰值小时数及来源指纹。GPU 活动率、板卡功率比、基础与空载 IT 电量份额均未用作可分配空闲卡的替代指标。

## 既有容量下的调度检验

采用[真实时钟调度结果](../flex-card-cost-calendar-20261102/README.md)。规划阶段分别优化风光储与市电接入，已建成情境固定为同参数无柔性最优配置。任务容量延续现有模型的动态任务功率峰值 K，新增容量为 e；每个观测小时满足动态任务功率不超过 K+e。

`planning-pairs.json` 专门比较禁止新增容量的柔性解与无柔性解，记录实际移位电量、任务功率容量和成本。`fixed-supply-pairs.json` 比较固定能源资产后的基准购置价格情境。全部情境的汇总配对同时检查最优状态、新增量接近零和实际移位量为正；本次另对 1,296 个训练算例独立验证同窗口服务量守恒、真实经过时间期限和逐时约束。其他连续时间来源保留既有计算结果，其验证范围与本次训练逐时审查分别记录。

规划阶段 528 个禁止新增容量的有效配对全部发生正移位；固定能源资产后的基准购置价格情境有 512 个有效配对，全部在新增任务容量不超过 1.02×10⁻¹⁰ MW 时发生正移位。其余 16 个固定资产无柔性组合仍为非最优状态，未用于配对统计。正移位只表示存在调度变化；固定资产的 100% 匹配目标仍可出现近零费用收益。

经济最优目标下，GPU 主导型训练的八城市中位移位量为每观测小时 0.739 MWh（规划）和 0.818 MWh（固定资产），对应费用差分别为 11.45% 和 5.66%。CPU 科研计算对应 0.828 和 0.967 MWh，CPU 云通用计算对应 0.448 和 0.454 MWh。这里的单位是窗口移位电量除以观测小时数，与实时空闲设备数量分别解释。

可推迟·整体与可推迟·可拆分的情境期限分别为 12 和 48 个实际小时。若下一条观测记录越过某批任务的截止时刻，该批任务必须在缺口之前完成。缺口没有任务执行变量，也没有补造负荷、天气或发电输入。全年数值仍属于按原生观测小时折算的等效年化量。

固定资产无柔性基线可复用同参数规划最优解：固定在该解对应的资产后，原最优点仍在收缩后的可行集中，因而达到同一最优值。复用记录保留逐项资产完全相等检查、原小时输出指纹及独立调度验收。

训练 1,296 例均在预先设定的 0.0001 MW/MWh 绝对容差内通过独立审查：有效执行量的最长时延分别为 12 和 48 小时，最大服务量守恒误差为 0.0000972 MWh，最大任务容量残差为 2.54×10⁻⁷ MW。完整逐例记录随真实时钟结果工作包保存；浮点量级的偏差保留在报告中。

## 结论的适用范围

该检验回答现有聚合功率模型是否存在使用既有容量完成移位的解。真实设备上的新增卡需求仍需逐任务 CPU/GPU 分配、显存与并行拓扑、完整作业连续执行约束、实际截止期和存档恢复成本支持。当前模型中的“可推迟·整体”仍采用可分配的小时工作量，尚未证明作业开始后连续执行；任务类型映射为研究情境权限。

不新增设备时，新增硬件支出可以为零；原有设备折旧、空载耗电和使用机会成本仍然存在。柔性成本节省百分比的分母为能源系统与新增算力成本，既有机群资本未计入该百分比。匹配目标 alpha 为逐小时供能后汇总的窗口电量匹配率。

# 情境命名（2026-10-29 用户确认：服务器类型 × 用途）

情境 = 服务器类型代码 + 用途代码，规模作后缀。例：D-TRN-100MW「GPU 主导型·大模型训练·100MW」。
数据来源只作为用途的建模依据，不进入情境名称。旧配置编号（C20/C21/C22/C28/R-GB200）保留为对照列。

## 维度 1：服务器类型（每台/每柜 CPU∶GPU）

| 代码 | 名称 | CPU∶GPU | 参考机型 | 旧编号 |
|---|---|---|---|---|
| A | 纯 CPU 型 | 2∶0 | Lenovo SR650 V3 双路 | C20 |
| B | CPU 主导型 | 2∶1 | SR650 V3 + 1×H100 PCIe | C21 |
| C | 均衡型 | 2∶2 | SR650 V3 + 2×H100 PCIe | C22 |
| D | GPU 主导型 | 2∶8 | DGX H100 | C28 |
| E | 纯 GPU 型（整柜液冷） | 36∶72 | GB200 NVL72 | R-GB200 |

E 型按颗数为 1∶2，但 Grace 只承担主机功能，按功率计 GPU 占整柜绝大部分（需按官方参数核算并在说明中写明比例），代表"基本纯 GPU"形态。

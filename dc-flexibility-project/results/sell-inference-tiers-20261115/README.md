# 第二节卖推理三层：理想上限、真实形状上限、上限的 25/50/75%（2026-11-15）

## 口径

- 计价：主结果 2.9 美元/GPU·时全天同价（DeepInfra H100 80GB 自定义部署价，2026-11-15 核对 https://deepinfra.com/pricing）。峰谷敏感性按 DeepSeek API 现行时段（周一至周五 UTC 01–04、06–10 时为高峰，不含中国法定节假日；其余半价），高峰 = 2 × 低谷，窗口内全时段平均价仍为 2.9。
- 不协同：原任务按原时序（真实上限层允许原任务在期限内推迟以腾出容量），不做电力调度。
- 三层售出量（按空闲 GPU 计，与地点无关）：ideal = 每小时闲置 GPU 全部售出；real_max = ASI 推理曲线形状、平均量 = 可承接上限 × 平均闲置 GPU；real_25/50/75 = real_max 的比例。
- 八城市（`sell_inference_tiers.py`）：额外能源成本 = 售出 GPU 小时 × 每卡动态任务功率 × PUE × (市电 100 + 碳价 100 × 碳因子)。
- 全球（`report_sell_inference_global.py`，4,842 网格 × 9 个 GPU 情境）：额外供能成本取第三节全球模型中同网格顺序调度下该层与 I=0 的供能成本差（风光储市电规划边界），再按 GPU 口径售出电量折算（`energy_scale`）。ideal 与 real_max 两层为补算（服务器 full-tiers，88,156 行全部最优）。
- 窗口：训练平移 14 天；科研 AI 截到与 ASI 重叠的 4,320 h；三层同窗口，按窗口小时年化。

## 结果（全球中位数，万美元/年，10 MW 参考机群）

| 情境 | 理想 | 真实上限 | 上限 50% | 峰谷（真实上限） | 第三节协同节省（上限 50%） |
|---|---|---|---|---|---|
| 训练 B/C/D-TRN | 6,805–9,939 | 5,330–7,769 | 2,663–3,883 | −2.5% | 52–81 |
| 科研 AI B/C/D-SAI | 11,166–16,145 | 2,589–4,338 | 1,294–2,169 | −2.5% | 38–76 |
| 推理 B/C/D-INF | 6,187–8,979 | 958–1,530 | 479–765 | −2.4% | 17–21 |

- 全球 P10–P90 与中位数相差不到 1%：售价相同，额外供能成本只占收入约 3%，地点几乎不影响卖推理的收入。
- 真实上限 ÷ 理想：训练约 78%，科研 AI 23%–28%，推理 15%–18%。
- 同一售出水平下，协同额外节省只占卖推理收入的很小一部分：上限 75% 时 0.8%–3.0%，上限 50% 时 2.0%–4.9%。

## 口径问题记录

任务功率与占用 GPU 不成固定比例（法兰克福 D-TRN 逐时每卡任务功率 P5–P95 为 0.34–0.59 kW，功率峰值与 GPU 峰值不在同一小时；按功率算闲置 36.4%，按 GPU 算 29.9%）。第三节的推理强度与可承接上限均以任务功率计；本表售出量按 GPU 计，额外供能成本相应折算（`energy_scale` 0.61–0.88）。第三节若改为以 GPU 数为容量约束，可承接上限会略低，待复核。

# 算电协同供能侧节省的分项拆分（2026-11-19）

回答两个问题：结论一至四里协同省下的供能成本具体省在哪几项；供能成本是否需要引入生命周期口径。

## 口径

- **对照**：顺序调度（不做协同，任务按原时间执行）与联合调度（算电协同）在同一网格、同一机群下配对。两种情况的光伏、风电、储能和市电接入容量**都按成本最优重新规划**，协同前并非全部使用市电。节省只计"挪任务"带来的部分，不含"自建风光比全买市电便宜"的部分。
- **分项**：节省 = 顺序 − 联合，逐项相减；正值为协同省下的钱，负值为协同为此多花的钱。分项分为风光（光伏+风电）、储能（功率+电量）、市电接入容量、市电电费、碳成本。
- **单位**：除以基准用电 E0（同网格、同情境、推理强度 0 时顺序调度的设施用电），单位为美元/MWh，与论文其余部分一致。
- **汇总**：`*_share_of_net_pct` 用网格均值计算（均值可加，正负相抵后合计 100%）；`saving_median_usd_mwh` 为中位数，与正文中的中位数一致。
- **成本年化（等年值，即全寿命成本）**：风光储资本费 × [CRF(8%, 寿命) + 固定运维占比]，其中光伏、风电寿命 25 年，储能 15 年；接入容量费 120 美元/kW·年；市电 100 美元/MWh；碳价 × Ember 2024 国家电网强度。未计光伏衰减、储能衰减与补容、残值、电价上涨。

## 主要结果

**结论一（碳价 100，不接推理，全部机群）**：净节省均值 10.0 美元/MWh，基准供能成本 111。按占净节省计，市电电费 +68%、接入容量 +29%、碳成本 +26%、储能 +11%、风光 −35%。中位数下，协同使市电电量占比从 38% 降到 31%，光伏从 2.0 增到 2.3 MW/MW 平均负荷，储能从 0.28 降到 0.10 小时，接入容量从峰值的 89% 降到 68%。云计算机群的储能占比最高（31%），训练机群的接入容量占比最高（34%）。

**结论二**：减配少耗的供能成本中位数为 6.6–13.8 美元/MWh，只占减配总节省的 1.9–4.1%，主要来自闲置待机电量减少（基准用电的 6–12%）。卖推理每新增 1 MWh 设施用电的边际供能成本为 99–114 美元/MWh，与平均供能成本相当。

**结论三**：推理强度从 0 增到上限的 75%，净节省均值从 10.0 降到 7.3，构成基本不变：市电电费 68–71%，接入容量约 30%，储能从 11% 降到 9%。

**结论四**：省钱方式随情景变化。碳价 0 时市电电费占 107%（风光 −55%）；碳价 200 时市电电费 44%、碳成本 30%、储能 26%；2035 年乐观路径（储能电量成本下降 70%）下储能占 57%、市电电费只占 19%。碳价越高、储能越便宜，系统本来就会多建储能，协同从"少买市电"转为"少建储能"，节省因此封顶。

## 占总成本

总成本 = 机群年化设备成本 + 供能成本，两者都是等年值（全寿命）口径：机群为 CRF(8%, 4 年) + 3% 运维（10 MW 参考机群，`results/global-flex-econ-20261103/part1/part1-summary.csv`），供能见上。机群成本按窗口小时分摊后除以窗口基准用电。每 MWh 总成本约 1,010–3,850 美元，其中供能成本占 3–9%。各表 `saving_share_of_total_cost_*` 为逐格比值的中位数、P90 与最大值。

| 结论 | 情景 | 占总成本（各机群中位数范围） |
|---|---|---|
| 一 | 碳价 100，不接推理 | 0.10–0.91%（单格最高 1.78%） |
| 三 | 推理 25/50/75% | 0.10–0.87% / 0.10–0.81% / 0.10–0.75% |
| 四 | 碳价 0 / 200 | 0.08–0.64% / 0.14–1.16% |
| 四 | 2030、2035 六条路径（机群成本按 2024） | 0.07–0.98% |
| 四 | 同上，机群成本按卡价路径 | 2035 保守 0.06–0.52%，中性 0.18–1.53%，乐观 0.29–2.54% |
| 二 | 减配总节省 / 其中供能部分 | 9.0–30.3% / 0.17–0.91% |
| 二 | 全卖净收入 / 其中额外供能成本 | 38–88% / 0.26–1.15% |
| 二 | 真实上限卖推理净收入 / 其中额外供能成本 | 5.9–45.4% / 0.05–0.87% |

第一节框架稿 1.3 节的 0.10%–0.94% 用第一节原生窗口；本表用第三节窗口（科研 AI 与 HPC 为与推理曲线重叠的窗口），差别来自窗口。卖推理来自 `results/sell-inference-tiers-20261115/sell-inference-global.parquet`（2.9 美元/GPU·时），表 `sec2-selling-supply.csv`。

## 排放口径检验（`lifecycle-emissions-check.csv`）

Ember 的电网强度采用 IPCC AR5 Annex III 的生命周期排放因子，而模型中自建风光储的排放记为 0。为检验这一不一致，在现有最优解上补算风光储的制造与建设隐含排放，按寿命摊到每年，不重新优化。取值分低/中/高三档，均为情景假设：

| | 低 | 中 | 高 | 依据 |
|---|---|---|---|---|
| 光伏（t CO2e/MW） | 800 | 1,300 | 1,800 | 高档约等于 IPCC AR5 中位 48 g/kWh 在容量因子 0.18、25 年下的换算；低、中档反映近年组件制造排放下降 |
| 风电（t CO2e/MW） | 600 | 800 | 1,100 | 中档约等于 IPCC AR5 中位 11 g/kWh 在容量因子 0.30、25 年下的换算 |
| 储能（t CO2e/MWh） | 50 | 70 | 100 | 锂离子电池组生产排放的常见范围 |

结果：碳价 100 时协同节省减少 0.7–3.5%（不足 0.5 美元/MWh）；碳价 200 时减少不超过 3.7%（云计算反而增加 0.6–1.0%）；2035 年乐观路径下协同节省增加 1.3–4.8%，因为此时协同主要靠少建储能。协同的运行减排为 8–39 kg/MWh，补隐含排放后只减少 0.5–4 kg/MWh。结论不随排放口径改变，因此主结果不重算。

## 局限

- 隐含排放检验是在现有最优解上的事后补算，没有把隐含排放计入优化目标；完全统一口径需要重跑全部算例。
- 碳价只作用于购电排放；隐含排放是否应承担碳价取决于政策边界（例如碳边境调节），这里作为上限检验处理。
- 与正文一致，仍为完全预知、不计实施成本。

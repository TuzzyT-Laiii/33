# 柔性收益占机群年化成本的比例

本结果复用已验证的全球优化配对表，覆盖4,842个有效网格、11个情境、六档本地无碳匹配目标和两种供能边界，共639,144组有效配对。原求解结果保持原样。

能源侧柔性收益率为同一窗口模型节省金额除以无柔性能源系统成本。当前全部最优解新增算力为零，模型节省等于能源成本差。既有机群成本未进入该指标的分母。

新增指标以同一窗口模型节省金额乘8760/有效小时数，除以既有机群年化成本，再乘100%。机群成本采用当前求解器的整机价格和等效台数：参考服务器台数乘原生窗口峰值利用率，再乘整机价和年化系数。年化系数为8%折现率、4年寿命的资本回收系数加3%固定运维，即0.3319208045。整机价格及等效台数为模型情境参数，未核实完整设备实物库存。`fleet-costs.csv`逐情境列出分母，核算结果与既有八城市求解记录一致。

严格使用“新指标大于3%”作为本研究设定的经济意义筛选条件。网格占比的分母为每个情境、每个目标、每种边界的4,842个有效网格，按网格等权统计。

经济最优条件下，全部情境和两种边界均没有网格超过3%，最高为1.866641%。已建成系统六档目标均未超过3%。规划阶段100%本地无碳匹配时，科研计算超过阈值的网格占比为64.394878%；GPU主导型训练为41.553077%。这些结果仅反映能源调度节省，未重新优化既有机群容量。

图件包括经济最优下规划阶段和已建成系统的11情境连续值地图、规划阶段100%本地无碳匹配的3%阈值地图，以及全部目标和边界的超过阈值网格占比图。两幅连续值地图共用0–3%色标；阈值图绿色表示严格大于3%，黄色表示小于或等于3%。沿用Robinson投影、Natural Earth 10m国界和2°区块陆地裁切方法，边界源文件SHA-256与原图一致。

`grid-metrics.parquet`保存逐网格指标，`scenario-summary.csv`保存132组情境目标边界统计，`brief-facts.json`用于生成简表，`verification.json`与`artifact-manifest.json`记录输入和输出校验值。源配对表、配置和原生窗口索引的哈希均保留。

复现时，从项目上一级目录运行：

```powershell
python dc-flexibility-project/analysis/plot_global_compute_cost.py --geography-run <原运行目录或包含相同sources及inputs结构的地图缓存目录>
```

地图缓存目录包含已核对SHA-256的`sources/countries-10m.zip`；`inputs/map-block-land-cells.parquet`若尚未存在，会按原脚本计算并缓存。图件使用matplotlib、Cartopy和frykit，中文字体通过`--font`指定。

等效年化金额为原生窗口折算，不代表完整全年实绩。延误、检查点恢复与有效产出损失尚未计价，因此该比例衡量节省规模，实际盈利判断仍需产出价值与运营成本证据。

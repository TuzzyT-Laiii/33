# 接入容量费与逐时碳因子敏感性（2026-11-21）

结果稿 v37 第一部分 1.3 新增的两条稳健性。口径同第三节全球结果：不接推理、碳价 100、2024 成本、规划边界；每对 = 不做柔性（seq）− 柔性（joint），÷ 同网格同情境的 seq 设施用电。

## 1 接入容量费（全球 4,842 网格 × 11 情境）

- `analysis/residual_flex_global.py --intensities 0 --fee {0,60,240}`（`launch-fee-full.sh`），每档 53,900 组、0 报错；120 取第三节全量。汇总 `analysis/fee_sensitivity_summary.py` → `fee-by-scenario.csv`。

## 2 逐时电网碳强度（德国、瑞典、美国 383 个网格 × 11 情境）

- 数据：Energy-Charts `public_power`（德国、瑞典，2025，15 分钟取小时均值）；EIA-930 Balance 2025（平衡区逐时分燃料净发电，取 Adjusted 列）。按发电结构 × IPCC AR5 生命周期中位数因子计算（煤 820、气 490、油 650、核 12、水 24、风 11、光 48 gCO₂/kWh 等），不计进出口。`analysis/hourly_ci_2025.py` → `hourly-ci-2025.csv`。
- 网格归属（`hourly-ef-grid-zones.json`）：德国、瑞典按国家；美国按经纬度粗分亚利桑那（AZPS）、加州（CISO）、得州（ERCO），其余用美国本土（US48）。这一归属是近似，未用平衡区边界。
- 逐时序列按小时缩放，使年均值等于模型中该网格的 Ember 因子，只检验时段差异。三种口径：年均因子（复现主结果，相对差 ≤2e-15）；同一调度按逐时核算；逐时因子进入碳成本后重新优化。`analysis/hourly_ef_run.py`（服务器 `/data3/dataset/ljt/hourly-ef-20261121`），4,213 组全部最优；`analysis/residual_flex_pilot.py` 改为支持逐时碳因子数组（标量时结果不变）。汇总 `analysis/hourly_ef_summary.py` → `hourly-ef-paired.parquet`。
